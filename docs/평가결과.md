### E3 제도 후보 누락률 — 0.10 → 0.00

측정 과정에서 **실제 결함 하나를 발견해 수정**했다.

`case_091`~`case_100`(연체 34일 등, 사전채무조정 대상) 10건에서 기대 제도가
결과 목록에 **아예 나타나지 않았다.** 원인은 `rules/engine.py` 의 정렬 기준이었다.

```python
# 수정 전 — status 가 priority 보다 앞
candidates.sort(key=lambda p: (_STATUS_RANK[p.status], p.priority, len(p.unknown)))
```

조건이 1개뿐인 보조 경로(금융회사 협의·법원 상담·복합지원)는 항상 `CANDIDATE` 가 되고,
조건이 많은 신복위 핵심 제도는 미확인 조건 하나만 있어도 `NEEDS_INFO` 가 된다.
status 를 먼저 정렬하면 보조 경로 3개가 `max_paths=3` 을 모두 채워
**연체구간이 맞는 핵심 제도가 화면에서 사라진다.**

연체 34일 이용자가 "법원 개인회생 상담"과 "복합지원"만 보고
정작 대상인 **사전채무조정을 안내받지 못하는** 상황이었다.

`NEEDS_INFO` 는 "해당 없음"이 아니라 "무엇을 확인하면 되는지 알려주는 상태"이므로,
priority 를 먼저 정렬하고 status 는 동순위 안에서만 쓰도록 바꿨다.

### 설명문 방어선 — 숫자 없는 응답이 그대로 노출되던 문제 (2026-09-02)

375px 워크스루 중 결과 화면(05)에 **`{}` 가 그대로 찍혀 있는 것을 발견했다.**

원인은 그라운딩 검증의 적용 범위다. `validate_grounding()` 은 "등장한 숫자가 허용 집합
안인가" 만 본다 — 설계대로다. 그런데 숫자가 하나도 없는 응답은 검사할 대상이 없어

키 없는 배포에서는 그 `{}` 가 설명문으로 채택돼 화면에 그대로 나왔다.

`generator._generate_section()` — 모든 설명문 구역이 지나가는 한 지점 — 에 한국어 산문
여부 검사를 추가했다. 템플릿 fallback 이 같은 내용을 항상 대신할 수 있으므로 의심스러우면
버린다. `{}` · 빈 문자열 · `N/A` · 영문 거절문에 대한 회귀 테스트를 함께 넣었다.

### E1 — 이전 측정: 로컬 오픈모델 0.9975, 과정에서 버그 2건 발견·수정

`ANTHROPIC_API_KEY` 없이 Qwen2.5-7B-Instruct(GGUF Q4_K_M, `llama-cpp-python`)로

1. **JSON을 ` ```json ` 코드펜스로 감싸 응답** — `LocalClient.complete()`에
   `response_format={"type": "json_object"}`(그래머 제약 디코딩)를 추가해 해결.

   Anthropic 경로에도 그대로 있던 잠재 결함. 영문 키 이름을 명시적으로

수정 후 재실행하니 55건 전체가 스키마를 만족했고, 필드별 F1도 대부분 1.0000이었다

`docs/고도화_아이디어.md`의 "LLM 대조 실험"에 해당한다. **E1~E6 핵심 지표에
포함되지 않는다** — "계산은 코드가 전담해야 하는 이유"를 주장이 아니라 증거로
보여주기 위한 1회성 실험이다. 같은 골든 케이스를 코드(결정론적 계산 모듈)와
LLM에게 각각 계산시켜 (1) 코드 대비 오차, (2) 동일 입력 2회 호출의 재현성을
대조한다.

이 저장소 환경에는 LLM 백엔드가 설정돼 있지 않아 `StubClient` 로 실행됐다
(STUB_MODE, 참고용 수치 — 실제 LLM 계산 성능이 아니다). **LLM API 키가
확보되면 `python3 eval/E4b_llm_direct_calc.py` 를 재실행해 진짜 값으로
갱신해야 한다.** 결과는 `reports/e4b_llm_direct_calc.md`에 남는다.

## 재현 방법

```bash
pip install -e ".[dev]"
export ANTHROPIC_API_KEY=...        # E1/E2 실측에 필요 (또는 아래 로컬 대안)
# 키 없이 무료로 하려면 대신:
#   pip install -e ".[dev,local]"
#   export DN_LOCAL_MODEL_PATH=./models/Qwen2.5-7B-Instruct-Q4_K_M.gguf
#   (다운로드 방법은 README "로컬 LLM으로 무료 실행" 참고)
python3 eval/E1_extraction_f1.py
python3 eval/E2_number_accuracy.py
python3 eval/E3_path_recall.py
python3 eval/E4_calc_consistency.py
python3 eval/E5_grounding_check.py
python3 eval/E6_safety_redteam.py
python3 eval/E4b_llm_direct_calc.py  # 참고용 — LLM 대조 실험, 핵심 지표 아님
python3 eval/report_builder.py       # reports/metrics_summary.md 생성
```

생성물은 `results/*.csv`, `reports/*.md` 에 남으며 두 경로 모두 gitignore 대상이다.
제출 전에는 `reports/metrics_summary.md` 의 내용을 이 문서에 반영한다.
