# 제출본

대회 제공 양식(HWPX)에 채워 넣는 최종 원고와 생성 도구.

| 파일 | 내용 |
|---|---|
| `기획서_양식본.md` | (첨부1) 기획서 7개 항목 |
| `기능명세서_양식본.md` | (첨부2) 기능명세서 5개 항목 |
| `../../tools/submission/` | 양식 치환 스크립트와 내용 원본(Python) |

## 생성 방법

```bash
# 대회가 배포한 빈 양식 HWPX 2개를 tools/submission/forms/ 에 둔 뒤
python3 tools/submission/fill_hwpx.py <출력디렉터리>
```

스크립트는 양식 XML 의 **안내문 문단**을 찾아 같은 서식의 문단 여러 개로 치환한다.
줄바꿈 위치 캐시(`hp:linesegarray`)는 넣지 않는다 — 한글이 파일을 열 때 다시 계산한다.

## 이력

- 2026-09-06 팀원 최종본(`실서비스반영_최종본`)을 기준으로 병합.
- 배포본과 대조해 사실 오류 2건을 고쳤다.
  - `새 세션 시작하기` → 실제 CTA(`개인정보 없이 2분 데모 체험` / `내 문서로 시작`).
    UX 개선으로 버튼이 바뀌었는데 문서가 옛 문구를 안내하고 있었다. 그대로 두면 심사자가
    첫 화면에서 막힌다.
  - `실행·만기일` → `실행일`. 추출 스키마에 만기일이 없고 `Debt.maturity_at` 을 채우는
    코드도 없다. 명세서는 구현된 기능만 적는 문서다.
- 팀원 판단 두 가지를 그대로 유지했다.
  - 표본 n=2 인 항목은 핵심 제출 수치에서 제외.
  - "외부에서 전체 E2E 를 독립 검증했다"고 표현하지 않는다. 자동 검증은 팀 내부 결과다.
